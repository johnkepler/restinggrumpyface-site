# restinggrumpyface: support

This repository is where **yaAnnotator** support happens. To ask a question,
report a bug, or request a feature, [open an issue](https://github.com/johnkepler/restinggrumpyface-site/issues).

Describe what you were doing, what you expected, and what happened.
Screenshots and your macOS version help a lot.

The website lives at [www.restinggrumpyface.com](https://www.restinggrumpyface.com).
It used to be published from this repository on GitHub Pages; it is now built
from a separate repository and served by Cloudflare.
