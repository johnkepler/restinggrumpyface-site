Keyboard shortcuts

The whole app is drivable from the keyboard. Here's the map.

File

New Library⌘N
New Project⇧⌘N
Import Images⌘I
Import Dataset Split⇧⌘I
Export Dataset⌘E

Edit

Undo / Redo⌘Z / ⇧⌘Z
Cut / Copy / Paste images⌘X / ⌘C / ⌘V
Select All⌘A

Cut / Copy / Paste move or duplicate the selected images, with their annotations, across projects and splits; pasting into a text editor drops the file paths instead.

Images (list / grid / single)

Open for editingReturn, or Space (grid / single)
Quick Look (list view)Space
Remove image(s)⌫
Move selectionarrow keys
Previous / next imagePage Up / Page Down
Extend selection⇧-click, or ⇧-arrow
Add / remove one from the selection⌘-click

In Quick Look: ← / → page through the list, Return opens the image for editing, Space closes it.

Editor: Tools menu

Delete Annotation⌘⌫
Combine Annotations⌘J
Convert to Rotated Box⇧⌘R
Accept All Proposals⌘↩
Paste Annotations from Previous Image⌥⌘V
Detect Multiple (RF-DETR)⌃⌘M
Detect with your custom model⇧⌘D
Toggle Approval⇧⌘A
Edit Labels⇧⌘L
Assign Label 1–9⌥⌘1 … ⌥⌘9

The other built-in detectors are menu-only, in Tools ▸ Detect. Any Detect command also runs over a multi-selection in the list or grid (no editor open): it proposes and auto-accepts across every selected image, warning first. Mark as Null / Unmark Null, Segment Selected Box, and the kind conversions (Convert Mask to Polygon, Convert to Box) also live in the Tools menu, without shortcuts.

Canvas

Select / Box / Polygon / Smart Select toolV / B / P / S
Close polygon / finish mask refinementReturn
Cancel / deselectEsc
Delete selected annotation(s)⌫
Delete picked polygon vertex⌫ (with a vertex picked)
Nudge the selection by one pixelarrows (⇧ = ten pixels)
Previous / next imagePage Up / Page Down, or arrows with nothing selected
Select several annotationsdrag a marquee on empty canvas
Drag without edge snappinghold ⌥ while dragging
Remove area from a selected mask⌥-click (Smart Select tool)

View

List / Grid / Single⌃⌘1 / ⌃⌘2 / ⌃⌘3
Zoom In / Out / Fit⌘+ / ⌘− / ⌘0
Show / Hide Inspector⌥⌘I
Show / Hide Labels (editor canvas)⌃⌘L

Canvas Layers (View menu, editor only) hides whole annotation kinds on the canvas, menu-only. Show Labels (⌃⌘L) hides just the label captions while the shapes still draw.
